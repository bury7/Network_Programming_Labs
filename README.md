# Network_Programming_Labs

This is a repository where you can find laboratory work I did as part of a network programming course at the university.

## Labs

- [Lab 1](lab_1) — HTTP requests and public APIs: NBU exchange rates, Telegram client and bot.
- [Lab 2](lab_2) — HTTP server with Flask: query parameters, headers, NBU rates and POST data storage.
- [Lab 3](lab_3) — REST API for a product catalog with HTTP Basic authentication, SQLite storage and a client.
- [Lab 4](lab_4) — Socket API: TCP echo server and client, text file transfer.
- [Pz 1](pz_1) — Unit tests with pytest and pytest-cov for the Lab 4 socket clients and servers.
